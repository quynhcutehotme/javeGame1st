# javeGame1st


“Bát Cháo Hành” is a 2D platformer game inspired by the classic gameplay of Super Mario, but redesigned with a uniquely Vietnamese identity to create a familiar yet refreshing experience. In this game, the player controls the main character as they navigate through obstacles, collect items, and explore a world filled with Vietnamese cultural elements — from rural village scenery and traditional markets to folk-inspired visual styles.
The project is developed using Java, with Java Swing and basic graphics libraries, aiming to deliver a lightweight and accessible game that can run smoothly on various systems while remaining easy to expand. A key focus during development is the application of Object-Oriented Programming (OOP) and SOLID principles, ensuring that the source code is clean, maintainable, and extensible. Game components such as the player, map, obstacles, scoring system, and enemies are designed as independent classes, each with clear responsibilities and minimal coupling.

Through this project, our objective is not only to develop a simple yet enjoyable game, but also to apply the programming knowledge and teamwork skills we have learned throughout the course. “Bát Cháo Hành” serves as the final group assignment, giving us the opportunity to consolidate OOP and SOLID principles, practice clean coding, and experience the full process of designing and implementing a game from scratch.
